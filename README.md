# Git Practical Exercises

## Aim
To learn and practice Git and GitHub commands for version control, repository management, and collaboration.

## Description
This repository contains 13 Git practical exercises covering basic Git commands, version control, branching, merging, remote repositories, and GitHub collaboration features.

## List of Exercises

1. **Create a Git Repository** – Initialize a local Git repository using `git init`.
2. **Create a File and Track Changes** – Create a file and track it using `git add`.
3. **Commit Changes to the Repository** – Save changes using `git commit`.
4. **View Commit History** – View commit history using `git log` and `git log --oneline`.
5. **Undo Changes Using Git Commands** – Undo unwanted changes using Git commands.
6. **Create, Switch, and Delete a Branch** – Manage branches using Git commands.
7. **Resolve a Merge Conflict** – Identify and resolve conflicts between branches.
8. **Store and Restore Changes Using Git Stash** – Temporarily save and restore uncommitted changes.
9. **Configure a Remote Repository** – Connect a local repository to GitHub.
10. **Clone, Push, and Pull Changes** – Synchronize changes between local and remote repositories.
11. **Fork a Repository and Create a Pull Request** – Contribute to another repository using GitHub.
12. **Collaborative Editing with Multiple Contributors** – Work together using a shared GitHub repository.
13. **Manage GitHub Issues and Project Boards** – Track and organize tasks using GitHub Issues and Projects.

## Technologies Used
- Git
- GitHub
- Command Line / Terminal

## Common Git Commands

```bash
git init
git status
git add .
git commit -m "Commit message"
git log --oneline
git branch
git switch main
git merge
git stash
git remote -v
git clone
git push
git pull
```

## Learning Outcomes

- Understand the basics of version control.
- Create and manage local Git repositories.
- Track, stage, commit, and undo changes.
- Create branches and resolve merge conflicts.
- Connect local repositories to GitHub.
- Collaborate with other contributors.
- Manage issues and project tasks on GitHub.

## Conclusion
These practical exercises provide hands-on experience with Git and GitHub for version control, project management, and collaborative software development.
